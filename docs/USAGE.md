# 使用教程

面向要把 MiniDocs 用起来的终端用户：个人博主、小型团队、工作室。读完你应该能：注册登录、
把一篇 Markdown 写成可分享的知识库、配好访问口令与有效期，并知道组织成员之间谁看得见谁、
谁能改什么。

想先看效果，可以逛线上演示 <https://docs.minims.cn>；想把它部署到自己的服务器，读
[部署指南](DEPLOYMENT.md)；功能与权限的完整规范见仓库 `docs/` 下的规范文档。

阅读顺序建议：第一次用，从 [1. 账号与登录](#1-账号与登录) 顺着往下读即可；
已经有部署好的实例，直接跳 [4. 创建知识库](#4-知识库管理) 开始写东西。

## 1. 账号与登录

### 1.1 注册与登录

打开站点首页，点右上角「登录」进入 `/login`：

- **已有账号**：直接登录。部署实例通常带一个内置管理员 `admin / admin123`，
  首次登录后请立刻改密码（见 [1.3](#13-账号设置)）。
- **没有账号**：点「注册」。注册成功后系统会**自动为你创建一个同名个人组织**，
  一个人也能立刻开始写。若站点关闭了自助注册（`REGISTER_ENABLED=false`），
  注册入口不可用，需要找平台管理员开通。

> 登录态过期后会退回登录页；分享页是给访客看的，不需要登录，二者互不影响。

### 1.2 两种界面

| 界面 | 地址 | 是什么 |
| --- | --- | --- |
| 阅读端 | `/`、`/kb/{org}/{kb}`、`/share/{token}` | 门户、阅读页、分享页，面向读者 |
| 工作区 | `/console/{org}/**` | 管理后台，面向作者与管理员 |

顶部导航在两种界面间切换：未登录看到「登录」，登录后从门户进工作区（`/console`）。

### 1.3 账号设置

`/account`（工作区顶栏头像菜单进入）可修改：

- 头像、昵称、密码（建议首访即改）
- 通知与外观类偏好（跟随站点设置）

改完即时生效，无需重启。

## 2. 界面导览

登录后落地在工作区首页，左侧导航按组织上下文组织：

| 页面 | 地址 | 干什么 |
| --- | --- | --- |
| 系统概览 | `/console/{org}/overview` | 组织维度的库、文档、分享统计 |
| 知识库管理 | `/console/{org}/kbs` | 建库、进库、配权限、发起分享 |
| 知识库工作区 | `/console/{org}/kbs/{slug}` | 全屏写作：目录树 + 编辑/预览 |
| 分享管理 | `/console/{org}/shares` | 所有链接一览：改口令、撤销、看访问量 |
| 组织设置 | `/console/{org}/settings` | 成员、角色、入组申请、组织资料 |
| 审计日志 | `/console/{org}/audit` | 谁在什么时候动了什么 |
| 账号设置 | `/account` | 改密码、头像 |
| 发现组织 | `/discover` | 浏览可申请加入的组织 |

> 地址里的 `{org}` 是当前组织的唯一标识。如果你属于多个组织，切组织请从顶栏的组织切换器走，
> 不要手改 URL——手改可能落到你没有权限的组织上（越权统一按 404 处理，不会提示「存在但你进不去」）。

## 3. 组织与成员

MiniDocs 是多租户的：**组织**是一道隔离墙，组织之间的知识库、成员、分享互不可见。

### 3.1 角色

| 角色 | 能干什么 |
| --- | --- |
| `OWNER` | 治理：改组织设置、任命/移除成员、删除库、分享、审批申请 |
| `EDITOR` | 读写：在「维护范围」允许的库里新建/编辑文档、发起分享 |
| `VIEWER` | 只读：看被授权的库 |

### 3.2 加入别人的组织

`/discover` 列出开放申请的组织，点「申请加入」后由该组织的 OWNER 在
组织设置页审批。审批通过即获得对应角色。

### 3.3 邀请与审批

OWNER 在 `/console/{org}/settings` 可以：

- 直接任命成员并指定角色
- 处理入组申请（通过 / 拒绝，重复申请是幂等的，不会刷出两条记录）
- 移除成员（被移除者下次请求即失去访问）

## 4. 知识库管理

### 4.1 创建知识库

`/console/{org}/kbs` 点「新建知识库」，填三件事：

| 字段 | 说明 |
| --- | --- |
| 名称与短名（slug） | 阅读页地址 `/kb/{org}/{slug}` 由它决定，短名全局唯一 |
| 可见性 | `public` 全站可发现 / `org` 仅本组织 / `private` 仅被授权者 |
| 维护范围 | `owner_only` 仅 OWNER 写 / `members` 有 EDITOR 角色的写 / `org_all` 组织内任何人可写 |

> 对团队协作，推荐 `org` + `members`：全组织可见，只有编辑能改。

### 4.2 知识库设置

进入库后，工具条的设置入口（齿轮）可改：

- 封面、简介、图标（门户卡片上展示）
- 可见性与维护范围（OWNER 专属）
- 维护名单：精确到人（VIEWER 也能被加进维护名单，只对该库生效）

「谁能读 / 谁能写」会实时显示当前档位下的实际效果，改档即生效。

## 5. 写文档

进入 `/console/{org}/kbs/{slug}` 是全屏工作区：中间编辑区，左侧目录树与大纲是浮层，
由工具条按钮开关。

### 5.1 目录结构

左侧文档树与阅读页目录一一对应。右键/悬浮操作可：

- 新建文档（自动落到所选层级）
- 新建分组（目录节点）
- 重命名、移动（拖拽调整父子关系）、删除
- 层级上限 6 层，单篇文档上限 2MB（超限会上传失败）

### 5.2 Markdown 编辑

编辑区支持 GFM 全量语法，`Ctrl / ⌘ + S` 保存，工具条切换「编辑 / 预览」：

- **GFM**：表格、任务列表、删除线、自动链接
- **代码块**：语法高亮 + 一键复制
- **Mermaid**：流程图、时序图等，` ```mermaid ` 围栏
- **KaTeX**：行内 `$...$`、块级 `$$...$$`
- **行内高亮**：`==文字==` → 琥珀色底纹，用来点出「这句是重点」
- **提示块**：引用块首行写 `[!TIP]` 之类的标记，见下表

```markdown
> [!TIP]
> 保存的快捷键是 Ctrl / ⌘ + S。

这段里 ==幂等== 两个字要划重点。
```

提示块共五种，标记写在引用块（`>`）的第一行，后面的内容照常写：

| 写法 | 渲染出的标题 | 颜色 |
| --- | --- | --- |
| `[!NOTE]` | 提示 | 蓝 |
| `[!TIP]` | 技巧 | 绿 |
| `[!WARNING]` | 警告 | 琥珀 |
| `[!IMPORTANT]` | 重要 | 紫 |
| `[!CAUTION]` | 注意 | 红 |

> [!WARNING]
> 提示块**不是** `!!! TIP "标题"` 那种写法。早期文档里写错过，这里更正一下：
> 三个感叹号在前后端都没有解析器，写出来只会原样显示成一段普通引用。

### 5.3 frontmatter

文档顶部可写元信息，会进目录树与检索：

```yaml
---
title: 部署检查清单
tags: [部署, 运维]
---
```

### 5.4 协作与保存状态

- **编辑锁**：同一文档同一时刻只有一个人能编辑。锁 60 秒续期，掉线/切页面超时后自动让位，
  后来者直接接管，不会读到半截内容。
- **乐观并发**：保存基于进入时的 size/mtime 基线。若期间别人（或另一个页面）改过，
  服务端返回 `412`，工具条状态胶囊会提示「落后」，刷新后再合入，不会静默覆盖。
- **状态胶囊**：把「有改动 / 落后 / 领先」合成一句话，跟着提示点按钮即可。

## 6. 阅读与检索

### 6.1 门户与阅读页

门户 `/` 按卡片列出可见知识库（`public` 对所有人可见，`org` 对组织内）。
点进去是阅读页 `/kb/{org}/{slug}`：

- 左侧目录树、右侧正文大纲（TOC），锚点跳转
- 上 / 下一篇导航
- 明亮 / 暗黑主题，跟随账号或手动切换

### 6.2 全文检索

门户或阅读页按 `Ctrl / ⌘ + K` 打开搜索面板：

- 站内全文检索（内存倒排索引，覆盖约 2000 篇以内）
- 命中直接给出文档标题链接，点即达

### 6.3 分享页

分享页 `/share/{token}` 与阅读页**共用同一条渲染管线**：作者看到的排版就是读者看到的。
分享页还有自己的小控件：可切换正文字体（思源黑体、霞鹜文楷等）与正文宽度；
配了导航菜单时，顶栏可在「全库 ↔ 栏目」间切换目录范围。

## 7. 分享

在知识库管理页或工作区点「分享」，打开分享对话框：

### 7.1 配置一个链接

| 选项 | 说明 |
| --- | --- |
| 范围 | 整库 / 单篇（指定一篇文档） |
| 读者 | 所有人（含未登录访客）/ 仅登录用户 / 仅本库维护者 |
| 访问口令 | 设了口令，首次访问需输入；通过后 12 小时免密（`SHARE_COOKIE_HOURS` 可调） |
| 有效期 | 到期自动失效，链接无需手动撤销 |
| 导航菜单 | 分享页顶栏入口，分享者自选读者能看到哪些栏目 |
| 自定义短链 | 6–32 位字母数字与 `-_`，跨组织查重全局唯一；留空自动生成 |

点「生成链接 / 更新链接」保存，复制即可发出。

> **换短链会二次确认**：旧链接立即失效，之前发出去的地址全部作废，改前想清楚。

### 7.2 管理链接

`/console/{org}/shares` 是所有分享的家：

- 改口令、改有效期、改短链（同样二次确认）
- 撤销链接：即刻失效，已通过口令的访客下次访问也被挡下
- 访问统计：按访问会话计数（30 分钟内同一访客只算一次），独立访客按天去重

> 站点基址要在「站点设置」里配对（见 [9.1](#91-站点设置)），否则复制出去的链接打不开。
> 这是部署期配一次的事，详见 [部署指南](DEPLOYMENT.md) 第 2 节。

## 8. 权限模型

三个维度正交组合，共同决定一次访问的结果：

| 维度 | 取值 | 管的是 |
| --- | --- | --- |
| 库可见性 | `public` / `org` / `private` | 谁能**看见**这个库 |
| 维护范围 | `owner_only` / `members` / `org_all` | 谁算这个库的**维护者**（能改） |
| 成员角色 | `OWNER` / `EDITOR` / `VIEWER` | 读 / 写 / 治理 / 分享 四条轴的判定 |

组合示例：

| 想达到的效果 | 配法 |
| --- | --- |
| 全站可读，只有我能改 | `public` + `owner_only` |
| 团队内部知识库，编辑们共建 | `org` + `members` |
| 给外部伙伴看一篇 | 单库 `private` + 建一条单篇分享链接 |
| 组织内自由写，我只管治理 | `org` + `org_all` + 你保持 OWNER |

细则（含越权一律 404 的处理策略）见仓库 `docs/` 下的权限规范文档。

## 9. 平台治理

平台级页面不带组织前缀，需要平台管理员（通常是内置 `admin`）进入。

### 9.1 站点设置

`/platform/site`：

- **站点基址**：复制出去的分享链接的地址前缀，**在这里改，改完立即生效，不用重启后端**
- 站点名称、Logo：门户与分享页的品牌

### 9.2 用户管理

`/platform/users`：禁用/启用账号、重置密码、分配平台角色。被禁账号立即无法登录。

## 10. 常见问题

**保存时报 412？**
你编辑期间有别人改过这篇。刷新页面拿到最新内容，重新合入你的改动再保存。

**看不到某个知识库？**
三种可能：可见性不够（找 OWNER 提权或加维护名单）、组织不对（切组织）、
或你不在该组织（去 `/discover` 申请）。注意越权一律返回 404，不代表不存在。

**分享链接打不开？**
按顺序排查：链接被撤销/过期 → 口令输错 → 站点基址配错（见 [7.2](#72-管理链接)）→
浏览器拦截了第三方 Cookie（分享口令 Cookie 作用域为根，勿用隐私模式组合拦截策略）。

**忘记管理员密码？**
内置管理员可用 `ADMIN_USER` / `ADMIN_PASS` 环境变量重置后重启；普通用户在登录页找「忘记密码」或由平台管理员在 `/platform/users` 重置。

**文档传到 2MB 上限了？**
单篇正文上限 2MB。大图请用外链或压缩，图片上传另有 20MB 上限（`minidocs.*` 阈值见
`application.yml`）。
